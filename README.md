# Testes de Acessibilidade

Aplicativo em Flutter para testes de acessibilidade com Semantics

## Sobre

Este projeto foi criado com o objetivo de explorar as funcionalidades do Semantics widget para
melhorar a acessibilidade de aplicações mobile utilizando Flutter e interagindo com recursos de leitura de tela, 
como o TalkBack (Android) ou o VoiceOver (iOS)

- [Artigo feito por mim (disponível na Medium)]([https://medium.com/@kelvindelima710/semantics-widget-no-flutter-explorando-a-acessibilidade-e-usabilidade-da-sua-aplica%C3%A7%C3%A3o-11282bdb71c9])
